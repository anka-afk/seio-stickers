# AstrBot娘表情包

收录 236 个 AstrBot娘动态表情，按 15 个聊天语义类别整理，适合日常对话、情绪表达与互动场景。

本项目是 `camera-2018/astrbot-seio-stickers` 的 AstrBot Meme Manager 适配包。

## 来源

- 原始资源仓库：https://github.com/camera-2018/astrbot-seio-stickers
- 原始发布版本：`v2026.09`（001–208）和 `v2026.10`（209–236）
- 使用的发布资产：`astrbot-seio-stickers-gif-240-500k.zip`
- 素材画师：`@失效药片`
- 原始资源整理：`camera-2018`

本适配仅重新组织目录和补充 Meme Manager 分类描述，没有修改 GIF 内容。`upstream-manifest.json` 汇总了各文件对应版本的上游文件名、大小和 SHA-256 信息，清单版本表示最新纳入的原始发布版本。
